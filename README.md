# Status da Bateria em Java

Projeto simples desenvolvido em Java para praticar Programação Orientada a Objetos (POO), encapsulamento e estruturas condicionais.

## Funcionalidades

- Definir o nível da bateria
- Validar valores entre 0 e 100
- Exibir o status da bateria de acordo com o nível de carga

## Tecnologias

- Java

## Estrutura

- `Bateria.java` → Classe responsável por armazenar o nível da bateria e informar seu status.
- `Main.java` → Classe principal que cria o objeto e exibe o status da bateria.

## Exemplo de saída

```
Status: Bateria cheia
```

## Regras

- 0 a 20 → Bateria fraca
- 21 a 79 → Bateria ok
- 80 a 100 → Bateria cheia
